# AuthSession UI Example

SwiftUI sample that uses `AuthSession` to complete Internet Identity login
against a local replica.

This example is a full package with:

- A SwiftUI app that logs in via `AuthSession` and calls a mainnet canister via IcpKit.
- An Xcode project (iOS + macOS targets) generated by XcodeGen.

## Prerequisites

- Rust toolchain
- DFX (Internet Computer SDK)
- Node.js (for building `ii-bridge`)
- Xcode 15+ / Swift 5.9 (iOS 16+ / macOS 13+)
- XcodeGen (`brew install xcodegen`)

## Setup

Provide a mainnet canister id that supports a `whoami` query method.
`authBridgeUrl` should point to the `ii-bridge` canister URL
(for example `https://<ii-bridge-canister>.ic0.app` on mainnet).

## Generate the Xcode project

```bash
xcodegen
```

Open `AuthSessionUI.xcodeproj`, choose iOS or macOS target, and run.

## In the App

- II Bridge Canister Id
- Backend Canister Id: a canister with `whoami`
- Redirect Scheme: `authsessionui`

Tap **Login** to open the `ii-bridge` canister (which in turn opens
Internet Identity), then **Call Backend** to verify `whoami`.

## Notes

- The app uses `AuthClient(serviceName:)` with default key type `Secp256k1`.
- The URL scheme `authsessionui://auth` is registered in both app targets.
